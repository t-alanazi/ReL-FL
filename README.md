# ReL-FL
ReL-FL: Transformer-guided Relational Reasoning for Update Prioritization in Federated Learning

Accepted at the IEEE/CVF Winter Conference on Applications of Computer Vision (WACV 2027).

ReL-FL is a transformer-guided framework for communication-efficient federated learning that learns inter-client relationships to prioritize updates under constrained communication budgets.
